# BoneSmashing Engine

Небольшой экспериментальный 3D-движок на Rust и `wgpu`. Сейчас это рабочая
основа для исследования рендеринга и импорта моделей: можно запустить
демонстрационную сцену, осмотреть PBR-материалы, загрузить модель и настроить
освещение. Сцены можно сохранять и открывать; полноценный редактор объектов
пока развивается.

## Возможности

- Рендеринг на `wgpu` с оконным циклом `winit`.
- PBR-материалы, HDR-освещение окружением (IBL), направленный свет и тени.
- HDR-буфер, ACES tone mapping и экранные эффекты для стекла.
- Импорт моделей `.glb`, `.gltf` и `.obj`.
- Сохранение и загрузка сцен с объектами, трансформациями и ссылками на модели.
- Панель настройки света, экспозиции, качества рендеринга и материалов.
- Камера от первого лица и тестовая сцена с несколькими материалами.
- Импортёр glTF читает скелеты и анимации; интерактивно импортированные
  модели пока отображаются в bind pose.

## Быстрый старт

### Требования

- Rust stable с поддержкой edition 2024 (установить можно через
  [rustup](https://rustup.rs/)).
- Графический адаптер и драйвер с поддержкой Vulkan, DirectX 12 или другого
  backend, доступного `wgpu` на вашей системе.

### Запуск

В терминале из корня проекта:

```powershell
cargo run
```

При первом запуске Cargo скачает зависимости и соберёт проект; после этого
должно открыться окно с демонстрационной сценой.

Чтобы дополнительно показать тестовые кубы и модели из `assets/models`,
запустите:

```powershell
cargo run -- --sample-assets
```

### Управление

| Действие | Управление |
| --- | --- |
| Захватить курсор и вращать камеру | Щёлкнуть мышью по окну |
| Двигаться | `W`, `A`, `S`, `D` |
| Подняться / опуститься | `Space` / `Shift` |
| Отпустить курсор | `Esc` |
| Показать / скрыть панель | `F1` |

Панель позволяет открывать и сохранять сцены, импортировать модели, выбирать
модель целиком или её отдельную именованную часть и редактировать трансформацию
выбранного уровня. Имена узлов и мешей берутся из glTF, их можно менять в
инспекторе. Общая трансформация модели перемещает все её части, а локальная
трансформация части позволяет настраивать её отдельно. Там же можно выбирать
HDR-окружение и настраивать свет, экспозицию, тени, режим отладки, масштаб
внутреннего разрешения, MSAA-сглаживание и параметры материала. Список режимов
MSAA зависит от адаптера и включает выключение и поддерживаемые уровни 2x, 4x
и 8x.

## Сохранение сцены

1. Нажмите `F1` и откройте раздел **Scene**.
2. Выберите **Save scene as...** и сохраните файл `.bse-scene`.
3. Чтобы восстановить сцену, нажмите **Open scene...** и выберите этот файл.

Файл сцены хранит модели-группы с общими трансформациями, имена и локальные
трансформации частей, а также ссылки на импортированные модели. Старые сцены
без групп автоматически собирают части одного импорта в группу; повторные
импорты того же файла сохраняются как отдельные модели. Загрузка моделей и
разбор файла идут в фоновом потоке; текущая сцена заменяется только после
успешной загрузки.
Если модель находится внутри папки проекта рядом со сценой, путь записывается
относительно сцены, и проект можно переносить вместе с файлами. Модели за
пределами этой папки записываются абсолютными путями и не будут переносимы
между компьютерами автоматически.

Сейчас в файл не сохраняются настройки света и HDR-окружения, изменения
параметров материалов, состояние камеры и воспроизведение анимации. У модели
поддерживается один уровень дочерних частей; произвольные вложенные группы и
удаление объектов пока не поддерживаются. Формат
сцен имеет версию и будет расширяться по мере развития редактора.

## Импорт моделей и окружения

### Модели

1. Нажмите `F1`, откройте раздел **Scene** и выберите **Import model...**.
2. Выберите `.glb`, `.gltf` или `.obj`.
3. Импортированная модель появится перед камерой.

Для моделей с материалами и текстурами предпочтителен `.glb`. Формат OBJ
поддерживается для геометрии; отдельные материалы из `.mtl` не загружаются.
Текстуры больших моделей ограничиваются по размеру и бюджету памяти при
импорте.

### HDR-окружение

В разделе **HDR environment** выберите файл `.hdr` или `.exr`. Нужна
панорама 360° в equirectangular-проекции, обычно с пропорцией 2:1, например
4096 × 2048. Обычная фотография, cubemap или панорама с другой проекцией не
подойдут. При ошибке загрузки предыдущее окружение остаётся активным.

Обработка HDR-карты для отражений PBR выполняется при загрузке. Для
выразительных отражений металла используйте окружение с контрастными
источниками света и деталями.
Загрузка и подготовка окружения, в том числе восстановление при запуске,
выполняются в фоновом потоке, поэтому окно остаётся отзывчивым. Пока окружение
готовится, используется временная заглушка; готовая карта включается после
завершения обработки.

### Материалы и ограничения рендера

Поддерживаются основные каналы glTF PBR, включая base color, metallic,
roughness, normal, occlusion и emissive, а также ряд расширений glTF для
specular, transmission, volume и specular-glossiness. Поддерживаются
несколько UV-наборов и `KHR_texture_transform`.

Стекло использует экранное преломление непрозрачной сцены: объекты за
поверхностью, не попавшие в экранный буфер, не видны в преломлении. Это
приближение, а не трассировка лучей. Точечные и прожекторные источники,
clearcoat и sheen пока не реализованы; параметры sampler из glTF пока не
применяются. Анимации импортируемых через интерфейс моделей пока не
воспроизводятся.

## Разработка

Полезные команды из корня проекта:

```powershell
cargo check
cargo test
cargo run
```

Основные части проекта:

| Путь | Назначение |
| --- | --- |
| `src/app.rs` | Окно, ввод, игровой цикл и демонстрационная сцена |
| `src/scene/` | Объекты сцены, трансформации и мир |
| `src/renderer/` | Рендеринг, материалы, меши, окружение, glTF и UI |
| `assets/models/` | Небольшие модели для тестирования импорта |

## Куда развивать дальше

Ближайшие цели — превратить рендерер в удобную основу для создания сцен:

1. Добавить создание и удаление объектов в редакторе.
2. Сохранять настройки сцены и материалы.
3. Развивать рабочий процесс редактора и подключать новые системы по мере
   необходимости.

Пока это ранний проект: публичный API и формат сцен не определены и могут
меняться. Лицензия проекта ещё не выбрана.
